# 環境再生プロジェクト

## 概念定義

環境再生とは、伝統土木・有機土木・大地の再生を含む統合概念。

水・空気・土・植生・人・経済の流れを一体として読み、「制御」ではなく「流れをいなす」視点で現場に向き合う。

## 基本姿勢

- 固定設計ではなく、現場判断を前提とする
- 施工だけでなく、維持管理・資金循環・教育設計までを射程に入れる
- 抽象（思想）から具体（現場）へ、段階を踏んで情報を整理する

